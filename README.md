#### KISS 
<i>= "Keep It Short and Simple" (or Keep It Simple, Stupid).</i>

It is a design principle that suggests simplicity should be a key goal.

<b>Most systems work best if they are kept simple rather than made overly complicated.</b>

- The core idea is to keep things as simple as possible while still achieving the desired functionality or outcome.
- This principle suggests that simpler solutions are typically easier to understand, implement, maintain, and use.

#### Cyclomatic Complexity Number (CCN)
is a software metric that measures the number of linearly independent paths through a program's source code.
